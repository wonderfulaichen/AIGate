AIGate

本地 LLM 网关

一个入口，接所有编程工具与所有供应商

Rust + axum · 单文件部署 · 零外部依赖

问题：配置碎片化

每个编程工具 × 每家供应商 = 一套配置

  • 3 种协议并存OpenAI /chat/completions、Anthropic /messages、OpenAI /responses —— 客户端与上游各说各话
  • 每个客户端都要单独配Cursor / Claude Code / Trae … 换供应商就得逐个改 base_url 与 key
  • 同名模型不能共存两家供应商都有 claude-opus 时，客户端里只能留一个
  • 花销与失败看不见用了多少、贵在哪、为什么 400/502 —— 全靠猜

方案：把复杂性收到一个本地网关

客户端只认一个 base_url；协议、路由、计量、韧性全在网关里解决

  • 协议自动匹配客户端打哪个入口，就用哪个协议转发；上游不支持才转换
  • 模型别名与共存中转 ID 与上游真名解耦；同名跨供应商各自成路由
  • 省量与计量剥离推理链 / 历史裁剪 / 响应缓存；逐请求记账与费用
  • 可观测与韧性请求日志、趋势、余额、熔断、重试、健康检查

协议自动匹配：由客户端入口决定

不是网关替你选协议，而是「请求决定」——网关只负责知道上游能接什么

怎么判

  • 客户端入口即意图：打 /v1/messages 就是在要 Anthropic 协议，命中即原生直通，不做格式转换
  • 上游能力实测：拉取模型时用 HEAD 探测端点（无请求体 → 零 token），带对照哨兵防「所有路径同状态」的假结果
  • 不做手工勾选：探测能力与配置/推断取并集，客户端打哪个入口就走哪条

为什么重要

  • thinking 块与 signature 全程不被往返翻译 —— 原生客户端的多轮思考/工具链不丢字段
  • 同一模型可同时服务三种客户端，不必为每个协议各起一个中转 ID
  • 实测：零声明下三入口分别直通上游 /chat/completions、/responses、/messages

省量机制：省在哪里，省多少

三种手段叠加，但必须说清口径 —— 否则容易高估

  • 剥离推理链多轮工具调用里把带 tool_calls 的 assistant 推理链剥掉（按模型开关，Anthropic 链路不剥以免 400）
  • 历史裁剪超长会话保留最近 N 轮，其余按需丢弃
  • 响应缓存相同非流式请求体命中即直接返回
  • 诚实口径剥离不破坏上游 KV 前缀缓存（实测相关系数 −0.03）；被剥内容绝大多数落在命中区，命中价与未命中价差数十倍 —— 所以省下的金额远小于 token 数给人的印象。决定成本的是上下文规模本身，不是剥离

界面：同一套设计语言，暗亮双主题

可观测性：把「花了多少、为什么失败」摆到台面

记录与统计

  • 逐请求日志：模型 / 供应商 / 状态 / 延迟 / token / 缓存命中 / 费用，可搜索、排序、列显隐
  • 趋势与分布：按上游模型拆分的 Token 趋势（平滑曲线 + 悬停十字线），调用分布环图与排名
  • 余额与费用：多供应商余额查询；费用三态（未配价 / 未命中配价 / 有值）如实呈现

失败可诊断

  • 错误本地化：上游英文错误翻成中文，并保留原文便于排障
  • 大请求体提示：4xx 且请求体 ≥1MB 时，直接给出体积与 token 量级，并提示「多为上下文超长或附件过大」
  • 降级可见：上游错误体解析失败等降级路径单独计数，不被静默吞掉

图表与详情：对齐参考项目的观感

韧性：坏上游不该拖垮整个会话

网关自己会闲时预检、坏时短路、退避重试

  • 熔断 + 半开探测连续失败即打开；到期后放行单个探测请求，成功即自动闭合（曾修掉「探测名额被同一请求消耗两次」导致永不恢复的缺陷）
  • 重试与退避仅对连接 / 超时错误与 5xx 生效，避免把参数错误重试成雪崩
  • 空闲超时上游长时间不吐数据即断开（可配 30~600 秒）
  • 请求体上限按供应商配置，超过即在网关侧拦下并给中文说明，不打到上游被裸拒

工程可信度：不是「看着能用」

每一处改动都有可执行的验证，且验证本身也被验证

  • 250 个单元测试含协议选择、错误文案、截断与错误分流、i18n 表等
  • 11 道前端门禁拼接自洽 / i18n 双表 / 纯函数单测 / IME 行为 / 加载并发 / 协议规则同源 / 标签配平 / 主题完整性 / 暗色零变化 / 对比度 / 变更日志格式
  • 端到端脚本隔离实例 + mock 上游：多协议路由、Responses 剥离、请求体提示等均在真实进程里跑通
  • 本轮修掉的 5 个真缺陷其中两个完全不可见：浮层全部落在前端框架作用域之外（抽屉/弹窗/Toast 全不工作）、分析页一个未闭合标签把后续所有页面吞进自己里面

架构：一个二进制，零外部依赖

为了「扔到机器上就能跑」，刻意做窄技术面

  • Rust + axum单进程、异步、无 GC 停顿；上游调用走 reqwest
  • 单 exe 交付前端（HTML/CSS/JS）由 include_str! 编译期切片拼接烤进二进制，不依赖 Node、不需要静态文件目录
  • 配置即文件providers.json 描述供应商与模型；密钥走环境变量或面板管理，不落明文
  • 可移植改端口 / 数据目录即隔离多实例；本项目的全部端到端验证正是靠这一点

开始使用

  1. 1
    构建 / 取 execargo build --release 或下载发行版，单文件
  2. 2
    启动AIGate.exe —— 默认监听 127.0.0.1:8787
  3. 3
    配供应商面板里新增供应商、填端点与密钥，「拉取模型」自动探测协议
  4. 4
    改客户端把编程工具的 API Base 指向 http://127.0.0.1:8787/v1 即可
